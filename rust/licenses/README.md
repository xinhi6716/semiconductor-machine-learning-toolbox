# Third-party notices

Every release archive includes THIRD_PARTY_LICENSES.json and copied license texts for all locked dependencies. Cargo.lock pins crate versions and checksums. The Git source checkout can obtain the original license files with the corresponding standard registry packages.

Release archives additionally include the Rust standard-library, Zig, MinGW-w64/UCRT, LLVM libunwind and musl notices under toolchain-notices. No Python interpreter is linked into the product binary.
